# KeyMouseMacro（键鼠模拟器）

[English](README.en.md)

Windows 下的键盘/鼠标模拟工具，支持连点、连按、持续按住和按键序列循环。单文件，零依赖（仅 Python 标准库），仅支持 Windows。

## 运行

安装 [Python 3](https://www.python.org/downloads/) 后，双击 `启动工具.bat` 或运行 `python main.py`。

加 `--lang=zh` / `--lang=en` 可强制界面语言，默认跟随系统。

## 功能

- 键盘任意按键（点击捕获按钮后按一下要模拟的键），或鼠标左/中/右键
- 动作模式：单次按下、持续按住、连续按 N 次、无限连发、序列循环
- 序列支持逐步间隔（毫秒）、循环轮数限制（0 为无限）、间隔随机 ±20%
- 全局热键，默认 F9 开始 / F10 停止，可自定义，在其他程序内有效
- 运行期间调高系统定时器精度，毫秒级间隔有效
- 停止即时生效，退出前保证松开按键
- 设置保存在 config.json，下次启动恢复；键盘和鼠标序列分开记忆

## 序列写法

动作用空格分隔：`1 2 3 4`、`q e r f1`、`左 右 左 右`。

- 键盘：字母、数字、F1~F24、方向键（up/down/left/right）、space/tab/enter/esc/shift/ctrl/alt、符号键（`-` `=` `[`）
- 鼠标：左/右/中，或 left/right/middle
- 空格键本身写 `space` 或 `空格`（空格是分隔符）
- 逐步间隔用冒号分隔：`2000:300:300` 依次为每步之后的等待毫秒数，第 n 个会替代循环间隔，个数不能多于步数

## 注意

- 目标程序以管理员身份运行时，本工具也要以管理员身份运行
- 部分游戏不识别模拟的"持续按住"，可改用"无限连发"
- 自动输入可能违反某些游戏或应用的条款，自行斟酌

详细说明见[使用说明.md](使用说明.md)。
